# Generic measured sweep evidence

Measured 2026-10-02 with Abaqus/Explicit 3DEXPERIENCE R2019x (Python 2.7.3 ODB reader), Windows and Python 3.12.14 workflow.
Both cases used B21, 10 elements, L=100 mm, h=1 mm, E=210000 N/mm², tip U2=-0.1 mm, T=0.25 s, double precision, no mass scaling.

These are selected immutable exports, not a runnable restored attempt directory. Status evidence hashes refer to private local attempt files; binary ODB, STA and console logs are deliberately not included. Run the published configuration to create your own attempts. Original config/input/history hashes are retained. No private specimen data is used.
